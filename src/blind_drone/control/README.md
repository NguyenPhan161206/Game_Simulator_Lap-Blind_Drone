# Điều khiển chuyển động

manual.py ánh xạ phím sang MotionCommand; stabilizer.py dùng trạng thái tự thân để tạo mục tiêu tốc độ cho bốn motor. Bộ trộn tuân theo vị trí lực và dấu phản lực của Webots Propeller. Không có scene API trong lớp điều khiển.

Actuator và cảm biến hiện lý tưởng, chưa hiệu chỉnh theo drone thật. Xem [giới hạn bản thử](../../../docs/lab-v1.md).
