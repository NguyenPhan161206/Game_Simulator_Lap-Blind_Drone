# Trách nhiệm khi phân công

Đây là các góc nhìn công việc; một agent có thể đảm nhiệm lần lượt. Chỉ chạy nhiều agent khi được cho phép.

| Vai trò | Kết quả cần bàn giao |
|---|---|
| Kiến trúc | Quyết định, hợp đồng dữ liệu và ranh giới phụ thuộc rõ ràng |
| Môi trường/phương tiện | World, va chạm, controller và giới hạn mô hình được kiểm tra |
| Cảm biến | Đầu ra, giới hạn quan sát, nhiễu, độ trễ, đơn vị và provenance |
| Điều hướng | Phương pháp dùng đúng dữ liệu được phép, so sánh với baseline |
| Đánh giá | Tình huống tái hiện được, phân loại kết quả, chia tập và thống kê |
| Rà soát | Lỗi rò rỉ trạng thái thật/vision, giả định sai và bằng chứng còn thiếu |
